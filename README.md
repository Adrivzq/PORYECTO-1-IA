# PORYECTO-1-IA

Proyecto base para desarrollo en Python con estructura de carpetas para datos, notebooks, tests y código fuente.

## Estructura

- `src/`: código fuente de la aplicación
- `data/`: datasets y archivos de datos
- `notebooks/`: notebooks de exploración y análisis
- `tests/`: pruebas automatizadas
- `config.py`: configuración centralizada del proyecto

## Requisitos

- Python 3.10+
- pip

## Instalación

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Ejecución

```bash
python main.py
```

## Variables de entorno

Puedes copiar el archivo `.env.example` a `.env` y ajustar los valores según tu entorno.

## Desarrollo

- Añade la lógica principal en `src/`
- Añade tests en `tests/`
- Mantén los notebooks para análisis exploratorio
